Entry for the make.fun bounty [One Line of Earned Pride](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557): a program that writes one line — a quiet, earned moment of pride for someone in a scene, a long effort finally landing.

Run with Node 22: `node main.ts` — writes the line to `/output/entry.txt`.

Design note: the program assembles the line from its scene beats and writes it verbatim — no randomness, no network, the same bytes on every run.
